# NOMAD Music UI

This checkpoint is a **UI-only redesign**. Backend APIs, database models, provider services, jobs, and Tauri plumbing are intentionally unchanged.

Highlights:
- Music-first home with artwork rails and personal-intelligence hero
- Unified search surface
- Cleaner library with source badges and indexing controls
- Playlist-first redesign with DNA / Flow / Doctor surfaces
- Dedicated Discover / Radio / Vibe Journey experience
- AI / Vibe control center
- Connection Hub for Spotify / YouTube / metadata providers
- Immersive lyrics and queue drawers
- Expanded now-playing surface
- Responsive desktop WebView layout
